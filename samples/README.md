# Mixr sample songs

Three short, copyright-free demo tracks for trying Mixr (and for App Review).
They are generated by `Scripts/generate_demo_songs.py`; the artists and titles
are made up.

On iPhone: open a link below in Safari, tap the download button, then in Mixr
tap **Import Songs** and pick the file from **Downloads** in the Files app.

- [Night Signals (Arlo Vance)](https://github.com/prlakshm/mixr/raw/main/samples/night-signals.m4a)
- [Velvet Static (Luma Vale)](https://github.com/prlakshm/mixr/raw/main/samples/velvet-static.m4a)
- [Paper Suns (Sable Coast)](https://github.com/prlakshm/mixr/raw/main/samples/paper-suns.m4a)
